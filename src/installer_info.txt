FrameGuard Desktop v0.7.1
Video QA for XR Deliverables


WHAT THIS INSTALLS

  FrameGuard Desktop
    Checks video files against your delivery specification and reports what
    passed, what failed, and why. A whole folder can be scanned in one pass.
    Failures sort first, with critical issues (corruption, unreadable files)
    ranked above minor ones.

  FFmpeg and FFprobe
    The video analysis engine. Bundled with this installer; no separate
    download or setup is required.

  MediaInfo
    Adds encoder and container detail to reports.

  Delivery presets
    4K UHD 30/60, 1080p 30, and 5.7K VR/360 profiles to start from. Your own
    presets can be saved and shared with your team as .fg files.


WHAT'S NEW IN v0.7.1

  Cross-platform UI release
    - The resolved application font is now installed before controls are built,
      preventing unusable fallback glyphs and mismatched text metrics on clean
      Windows profiles and headless validation systems.
    - Windows caption controls, Results summary metrics and Checks headings now
      reserve space from their realized font metrics.
    - A shutdown-time update check can no longer emit through a deleted Qt
      signal source.
    - Every application-owned control
      all 15 themes, including disabled, focused, selected and error states.
    - First launch follows the operating system appearance and opens with
      screen-safe geometry without creating an output folder prematurely.
    - Scan, Watch Folder and Settings adapt cleanly to short or narrow screens.
    - Results and Checks tables use actual font metrics so headers, long names,
      summaries and failure counts remain readable at supported DPI scales.
    - macOS keeps its native title bar and window behavior; Windows preserves
      DWM, resize, Aero Snap, Snap Layouts and the native system menu.
    - Keyboard focus, accessible names, label buddies, contrast and practical
      interaction targets have automated coverage.
    - CI renders populated interfaces at three sizes and four DPI scales and
      preserves JSON and screenshot evidence for any regression.


BEFORE YOU INSTALL

  Requirements
    Windows 10 or Windows 11, 64-bit
    4 GB RAM minimum, 8 GB recommended for large batches
    500 MB free disk space

  If FrameGuard is running when Setup starts, Setup will close it
  automatically.


PRIVACY

  All processing happens on this computer. FrameGuard does not upload,
  transmit, or share your video files or scan results.
