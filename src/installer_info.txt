FrameGuard Desktop v0.8.0
Video QA for XR Deliverables


WHAT THIS INSTALLS

  FrameGuard Desktop
    Checks video files against your delivery specification and reports what
    passed, what failed, and why. A whole folder can be scanned in one pass.
    Failures sort first, with critical issues (corruption, unreadable files)
    ranked above minor ones.

  FFmpeg and FFprobe
    The video analysis engine. Bundled with this installer; no separate
    download or setup is required.

  MediaInfo
    Adds encoder and container detail to reports.

  Delivery presets
    4K UHD 30/60, 1080p 30, and 5.7K VR/360 profiles to start from. Your own
    presets can be saved and shared with your team as .fg files.


WHAT'S NEW IN v0.8.0

  Shipped-path reliability
    - Source, frozen, installed and mounted applications now exercise the same
      bounded startup path before a release can be published.
    - Scan cancellation is isolated per worker, malformed media metadata fails
      safely, and FFmpeg diagnostics remain memory-bounded without discarding
      early or late defect evidence.
    - Watch folders distinguish same-size rewrites and replacements, reject
      unsafe symlinks, and preserve queued files across low-disk interruptions.
    - Presets, PDF exports, media launching and updater downloads now use
      deterministic limits, integrity checks, cancellation and cleanup.
    - Full-installer updates require exact platform assets and published
      SHA-256 evidence before an installer can run.

  Exact-SHA native release proof
    - Local pre-push checks fingerprint the source tree, toolchain, logs,
      manifests, review metadata and local package bytes without claiming
      cross-platform release authorization.
    - GitHub blocks release tags until Windows, Apple Silicon and Intel package
      builders and installed or mounted startup smokes pass for the exact commit.
    - Release jobs rebuild only that verified commit and recheck the annotated
      tag immediately before publication.


BEFORE YOU INSTALL

  Requirements
    Windows 10 or Windows 11, 64-bit
    4 GB RAM minimum, 8 GB recommended for large batches
    500 MB free disk space

  If FrameGuard is running when Setup starts, Setup will close it
  automatically.


PRIVACY

  All processing happens on this computer. FrameGuard does not upload,
  transmit, or share your video files or scan results.
