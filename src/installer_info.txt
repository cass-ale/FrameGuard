FrameGuard Desktop v0.6.1
Video QA for XR Deliverables


WHAT THIS INSTALLS

  FrameGuard Desktop
    Checks video files against your delivery specification and reports what
    passed, what failed, and why. A whole folder can be scanned in one pass.
    Failures sort first, with critical issues (corruption, unreadable files)
    ranked above minor ones.

  FFmpeg and FFprobe
    The video analysis engine. Bundled with this installer; no separate
    download or setup is required.

  MediaInfo
    Adds encoder and container detail to reports.

  Delivery presets
    4K UHD 30/60, 1080p 30, and 5.7K VR/360 profiles to start from. Your own
    presets can be saved and shared with your team as .fg files.


WHAT'S NEW IN v0.6.1

  Release reliability
    - macOS disk-image verification now retries transient system failures
      instead of discarding a valid Apple Silicon build.
    - Windows, Apple Silicon, and Intel run the same pinned full test suite
      before a release tag is created.
    - Python, packaging, and test dependencies are constrained to the
      versions proven by all three builders.
    - Official macOS signing and notarization fail closed when configured;
      internal ad-hoc builds continue to work without Apple credentials.
    - Release drafts resume safely after an interrupted run, and the update
      channel is committed before an immutable release is published.
    - GitHub Actions now use reviewed Node 24-compatible revisions and
      retain build diagnostics when a platform fails.


BEFORE YOU INSTALL

  Requirements
    Windows 10 or Windows 11, 64-bit
    4 GB RAM minimum, 8 GB recommended for large batches
    500 MB free disk space

  If FrameGuard is running when Setup starts, Setup will close it
  automatically.


PRIVACY

  All processing happens on this computer. FrameGuard does not upload,
  transmit, or share your video files or scan results.
