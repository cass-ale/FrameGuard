# AGENTS.md

Cut taglines, helper text and secondary labels. If a screen needs them to make sense, fix the layout.

Make the best decision that will elevate all three: the user experience (UX), developer experience (DX), and agent experience (AX) always, without breaking anything.

## Standing rules adopted 2026-10-22

- Design (Hallmark, adopted for all repos): any web page or generated HTML with design weight follows the Hallmark floor: no invented metrics or testimonials, focus-visible on every interactive element, a reduced-motion fallback, no eyebrow or tracked-capital labels, no purple-blue gradients or cards-in-cards, design tokens at :root instead of literal colours and fonts. Existing pages are audited before any redesign. Where Hallmark and Cassian's own rules conflict, Cassian's rules win.
- Show, don't describe: when an answer is data (reports, benchmarks, comparisons), deliver a chart or visual, not prose about one, and check the data before plotting it (duplicates, gaps, impossible values).
- Skills authored for work in this repo name five things: when to use it, what it needs from Cassian, the steps, what the output looks like, and what it must never do.
- Depth over size: work from the primary artifact, verify through an independent channel (the rendered output, never just the data that generated it), and state what was checked and what was not.
