# Security Policy

## Supported versions

Only the latest published release of FrameGuard is supported with security updates. If you are running an older version, please update first: FrameGuard checks GitHub Releases automatically and offers the correct installer for your platform and architecture.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability.

Report it privately through GitHub: open this repository's **Security** tab and choose **Report a vulnerability**. If that route is unavailable to you, email **admin@caprilaria.com** with "FrameGuard security" in the subject line.

Please include the FrameGuard version, your operating system, and the steps that reproduce the problem. You can expect an acknowledgement within a few days. Confirmed vulnerabilities are fixed in a new release, and the release notes will credit the reporter unless they prefer to remain anonymous.

## Reporting other problems

Bugs and feature requests that are not security-sensitive belong in [GitHub Issues](https://github.com/cass-ale/FrameGuard/issues).
