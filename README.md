# FrameGuard
**Video QA for XR deliverables — Windows and macOS.**
FrameGuard validates video files against configurable delivery specifications: automated checks across metadata, codec compliance, audio integrity, and deep signal analysis (black/freeze frame, silence detection, decode integrity). Everything runs locally — no data leaves the machine. Built for XR production pipelines: batch processing, folder-watch auto-scan, and PDF handoff reports.

The application lives in `FGv0.2.2/` — start with its README for the full feature list, and BUILD_README.md for building the Windows/macOS installers.
